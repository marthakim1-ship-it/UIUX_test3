## 3. 오류 수정 보고

### 결함 1

| 항목 | 작성 내용 |
|---|---|
| 결함 ID | BUG-01 |
| 선택자 | `.con` (`layout_cpn.css`) |
| 문제 선언 | `max-width: var(--containner);` — `--containner` 변수가 선언되어 있지 않음 |
| 화면 증상 | 넓은 화면에서 컨테이너 최대 폭이 적용되지 않아 콘텐츠 폭과 좌우 정렬이 정답 화면과 다름 |
| 진단 방법 | `root.css`에서 `--containner`를 검색했으나 정의가 없고, 정의된 1600px 토큰은 `--grid-1600`임을 확인함. 따라서 Computed의 `max-width` 선언은 무효 처리됨 |
| 필요한 수정 선언 | `max-width: var(--grid-1600);`로 변경 |
| 현재 상태 | 미수정 — 문제 파일과 제출 파일에 동일한 오답 선언이 남아 있음 |
| 수정 전/후 증빙 | 미제공 |

### 결함 2

| 항목 | 작성 내용 |
|---|---|
| 결함 ID | BUG-02 |
| 선택자 | `.grid-5` (`layout_cpn.css`), `.product-grid` (`style.css`) |
| 문제 선언 | `grid-template-columns: repeat(5 1fr);` — 반복 횟수와 트랙 크기 사이의 쉼표 누락. 추가된 `.product-grid { display: flex; }`가 앞서 선언한 Grid도 덮어씀 |
| 화면 증상 | BEST PICKS 상품이 정상적인 5단 Grid로 배치되지 않음 |
| 진단 방법 | Grid/Styles에서 `grid-template-columns`가 문법 오류로 무효 처리되고, 뒤에 로드되는 `style.css`의 `display: flex`가 `.grid-5`의 `display: grid`를 덮어쓰는 것을 확인함 |
| 필요한 수정 선언 | `.grid-5 { display: grid; grid-template-columns: repeat(5, 1fr); }`로 고치고 `.product-grid`의 `display: flex`를 제거하여 `margin-top`만 유지 |
| 현재 상태 | 미수정 — 수정 전후 이미지는 있으나 제출 CSS는 5단 Grid 수정 조건을 충족하지 않음 |
| 수정 전/후 증빙 | `제출 파일/수정전후파일/BEST PICKS_수정전.png`, `제출 파일/수정전후파일/BEST PICKS_수정후.png` |

- CSS 파일 분리 기준을 정한 방법: 과제안내서의 8개 역할(기본 스타일, 원시 변수, 의미 변수, 버튼, 항목, 레이아웃, 페이지, 반응형)을 기준으로 분리했다.

- 다시 수행한다면 개선할 점: 분리 직후 원본과의 시각 회귀 테스트를 하고, 각 결함을 한 건씩 수정한 뒤 1920/1600/1024/768/480px에서 다시 확인한다.
